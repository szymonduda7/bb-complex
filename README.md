# B&B Complex

Strona wizytówka producenta mebli na wymiar w Stalowej Woli (index.html + uslugi.html).

- `index.html`: hero w stylu banera, o firmie, podgląd usług, galeria realizacji z lightboxem, film, ocena Google, kontakt z mapą
- `uslugi.html`: karty usług (kuchnie, łazienki, szafy przesuwne, garderoby, zabudowy i siedziska, biurka i komody)
- `styles.css`, `main.js`: wspólne style i skrypty
- `images/*.webp`, `videos/bb-complex.mp4` (przycięty z `company-video.mp4`), `videos/poster.webp`

Tailwind CSS i ikony Lucide z CDN, fonty Red Hat Display + Public Sans.
